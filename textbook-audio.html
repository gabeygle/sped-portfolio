The Textbook, Read Aloud

An accessibility project I built for myself

Module 8 — additional artifact of my choice. Not a graded assignment. Something I built because I needed it.

I do a lot of my reading while commuting in Taipei, and the course textbook — Friend's Interactions: Collaboration Skills for School Professionals — has no audiobook. So I wrote a small script that extracts each chapter to plain text and narrates it with the macOS speech engine, producing an .m4a per chapter that I can play like a podcast.

I am including it here because it is the clearest example of a principle this course kept returning to: access is something you build, and you usually build it because someone specific needs it. In this case the someone was me. The same script would work for a student who reads slowly, or one who processes spoken language better than print — which is exactly the population I teach.

Listen: Chapter 1

Friend, M. (2021). Interactions: Collaboration skills for school professionals (9th ed.). Pearson. Narrated with the macOS say engine (voice: Zoe, Premium) for personal study use.

The script

A short shell script: it walks a folder of Chapter_*.txt files, pipes each through say, and writes an .m4a alongside it.
